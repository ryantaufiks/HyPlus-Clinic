│ 🛑 STOPPING & RESTARTING                                                     │
└──────────────────────────────────────────────────────────────────────────────┘

  Stop Server:         Double-click → stop_server.bat
                       OR press Ctrl+C in console window

  Restart Server:      Double-click → restart_server.bat

  Force Kill:          netstat -ano | findstr :8001
                       taskkill /PID <PID> /F

┌──────────────────────────────────────────────────────────────────────────────┐
│ ⚠️ TROUBLESHOOTING                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

  "Virtual environment not found"
  ════════════════════════════════════
  → Run: autorun_advanced.bat
  → Select: [7] Install/Update Requirements


  "Port 8001 already in use"
  ════════════════════════════════════
  → Run: stop_server.bat
  → Then: quick_start.bat


  "Module not found" / Import errors
  ════════════════════════════════════
  → Run: autorun_advanced.bat
  → Select: [7] Install/Update Requirements


  Server hangs or not responding
  ════════════════════════════════════
  → Run: restart_server.bat


  Need database reset
  ════════════════════════════════════
  → Run: autorun_advanced.bat
  → Select: [4] Run Migrations Only


┌──────────────────────────────────────────────────────────────────────────────┐
│ 📋 FIRST TIME SETUP (Step by Step)                                          │
└──────────────────────────────────────────────────────────────────────────────┘

  1. Install Requirements
     → Double-click: autorun_advanced.bat
     → Select: [7] Install/Update Requirements
     → Wait for completion

  2. Create Admin User
     → Double-click: create_admin.bat
     → Enter username, email, password
     → Confirm when done

  3. Start Server
     → Double-click: quick_start.bat
     → Browser opens automatically
     → Login at /admin with your credentials

  4. You're Ready!
     → Kiosk is now operational
     → Access via: http://127.0.0.1:8001
