🌐 METHOD 2: REMOTE ACCESS WITH CLOUDFLARE (15 MINUTES)
═══════════════════════════════════════════════════════════════════════════════

For accessing from ANYWHERE (not just local network):


📍 STEP 1: Install Cloudflared
──────────────────────────────────────
  Windows:
  winget install --id Cloudflare.cloudflared

  Or download from:
  https://github.com/cloudflare/cloudflared/releases

  Verify:
  cloudflared --version


📍 STEP 2: Login to Cloudflare
──────────────────────────────────────
  cloudflared tunnel login

  (Browser opens for authentication - use FREE account)


📍 STEP 3: Create Tunnel
──────────────────────────────────────
  cloudflared tunnel create ai-nurse-tunnel

  SAVE the Tunnel ID that appears!


📍 STEP 4: Configure Tunnel
──────────────────────────────────────
  Create file:
  C:\Users\[YourUser]\.cloudflared\config.yml

  Content:
  ┌─────────────────────────────────────────────────────┐
  │ tunnel: ai-nurse-tunnel                             │
  │ credentials-file: C:\Users\[YourUser]\.cloudflared\ │
  │                   [TUNNEL-ID].json                  │
  │                                                     │
  │ ingress:                                            │
  │   - hostname: ai-nurse.yourdomain.com               │
  │     service: http://localhost:8001                  │
  │   - service: http_status:404                        │
  └─────────────────────────────────────────────────────┘

  Replace:
  • [YourUser] with your Windows username
  • [TUNNEL-ID] with your tunnel ID
  • yourdomain.com with your domain


📍 STEP 5: Add DNS Record
──────────────────────────────────────
  cloudflared tunnel route dns ai-nurse-tunnel ai-nurse.yourdomain.com

  Or manually in Cloudflare Dashboard:
  • DNS → Add Record
  • Type: CNAME
  • Name: ai-nurse
  • Target: [TUNNEL-ID].cfargotunnel.com


📍 STEP 6: Update Django Settings
──────────────────────────────────────
  Edit: C:\AI_Nurse\monolith\health_kiosk\settings.py

  Find ALLOWED_HOSTS and add:
  ALLOWED_HOSTS = [
      "localhost",
      "127.0.0.1",
      "ai-nurse.yourdomain.com",
  ]

  Find CSRF_TRUSTED_ORIGINS and add:
  CSRF_TRUSTED_ORIGINS = [
      "http://localhost:8001",
      "https://ai-nurse.yourdomain.com",
  ]


📍 STEP 7: Start Everything
──────────────────────────────────────
  Terminal 1 - Django Server:
  cd C:\AI_Nurse
  quick_start.bat

  Terminal 2 - Cloudflare Tunnel:
  cloudflared tunnel run ai-nurse-tunnel


📍 STEP 8: Access from ANYWHERE!
──────────────────────────────────────
  Open browser on ANY device:
  https://ai-nurse.yourdomain.com

  Install PWA:
  • Chrome → Menu → "Add to Home screen"
  • Safari → Share → "Add to Home Screen"

  ✓ Works from anywhere with internet!
  ✓ Secure HTTPS connection!
  ✓ All features work remotely!

⚠️  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: "Add to Home Screen" not showing
Solution: Use Chrome browser, access via HTTPS (Cloudflare)

Problem: Can't access from phone
Solution: Check same WiFi, check firewall, use correct IP

Problem: Bluetooth not working
Solution: HTTPS required (use Cloudflare), grant permissions

Problem: Service Worker error
Solution: Clear cache, hard refresh (Ctrl+Shift+R)

Problem: CORS error
Solution: Update ALLOWED_HOSTS in Django settings.py
