⚠️  FIRST TIME SETUP (IMPORTANT!):
═══════════════════════════════════════════════════════════════

  Before starting the server for the first time:

  👉 STEP 1: INSTALL PACKAGES
  ──────────────────────────────────────
  Double-click: install_packages.bat

  This will:
  ✓ Create virtual environment
  ✓ Install Django
  ✓ Install QR code generator
  ✓ Install image processing library

  (This only needs to be done once!)


  👉 STEP 2: CREATE ADMIN USER
  ──────────────────────────────────────
  Double-click: create_admin.bat

  Enter your admin username and password
  (You'll use this to login to admin panel)


═══════════════════════════════════════════════════════════════

📌 HOW TO START THE SERVER (DAILY USE):
═══════════════════════════════════════════════════════════════

  👉 METHOD 1: FASTEST WAY (Recommended)
  ──────────────────────────────────────
  Double-click: quick_start.bat

  ✓ Server starts on port 8001
  ✓ Browser opens automatically
  ✓ Ready to use!


  👉 METHOD 2: WITH AUTO-MIGRATION
  ──────────────────────────────────────
  Double-click: autorun.bat

  ✓ Checks and runs database migrations
  ✓ Shows detailed progress
  ✓ Opens browser automatically


  👉 METHOD 3: ADVANCED OPTIONS
  ──────────────────────────────────────
  Double-click: autorun_advanced.bat

  ✓ Full menu with 9 options
  ✓ Create admin users
  ✓ Custom port selection
  ✓ System diagnostics

⚠️ TROUBLESHOOTING:
═══════════════════════════════════════════════════════════════

  Problem: "Virtual environment not found"
  Solution: Run install_packages.bat

  Problem: "Module not found" or "Import error"
  Solution: Run install_packages.bat to install packages

  Problem: "Port 8001 already in use"
  Solution: Double-click stop_server.bat then try again

  Problem: QR code not appearing
  Solution: Make sure you ran install_packages.bat first

  Problem: Need to restart server
  Solution: Double-click restart_server.bat
